# Common Agent Rules (kernel)

<!-- AGENT-KERNEL v1 -->

## Kernel

- 默认简体中文 + Markdown；回答简洁、可执行；不编造事实、工具输出、私有状态、日期或不可得信息。
- 只读写当前 workspace；外部路径必须来自用户显式路径、已登记资产或必要工具元数据。
- 执行动作前明确目标、边界、验收；用户明确要求“实现 / 修复 / 修改 / 落地”即授权在当前 workspace 内完成该目标，后续设计细化、依赖补齐、同范围文件扩展和验证直接执行；分析、审查、状态询问不授权写入；目标越界、生产/外部写入、安全升级、删除或不可逆动作先确认。
- 临时文件统一写入 `.tmp/`；新文件优先 `UTF-8 without BOM + LF`。
- 最小有效改动；不做无关重构、清理、投机抽象或投机配置。
- 复用既有 skill、docs、脚本和项目真源；不新增并行真源。
- 失败必须定位根因，并沉淀为 `insight / anti-pattern / checklist / test / docs` 之一。
- 命令执行、工具差异和平台细节遵循本文件中的环境规则。
