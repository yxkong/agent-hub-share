# 风险分级与人工确认矩阵

> 下列场景 **Agent 必须暂停**，列出风险与拟议动作，**经用户明示确认**后再继续。

## 风险等级

| 等级 | 含义 | 默认动作 |
|------|------|----------|
| **P0** | 数据丢失、安全越权、生产不可用 | 禁止执行，升级人工 |
| **P1** | 不可逆 migration、权限模型变更、大范围重构 | 需 ADR + 人工确认 |
| **P2** | 跨模块契约变更、性能敏感路径 | Task Contract + 人工确认可选 |
| **P3** | 单点逻辑、可快速回退 | Agent 可继续，记录 risk |

## 必须人工确认的场景

| 场景 | 等级 | 需确认的内容 |
|------|------|--------------|
| `git restore` / `reset` / `clean` 等丢改操作 | P0 | 范围清单 + 命令原文 |
| 写入 `docs/db/online/` | P0 | 禁止 Agent 执行 |
| 生产环境命令（deploy / 远程 DB） | P0 | 用户未显式要求则禁止 |
| 删除 / 清空已有文档或 SQL | P0 | 负责人确认 |
| 不可逆 DDL（DROP / 删列无备份） | P1 | 回滚方案 + ADR |
| 权限 / 租户模型变更 | P1 | Security Gate + ADR |
| 密钥 / token 轮换 | P1 | 影响面说明 |
| 跨仓库 / 跨团队接口破坏性变更 | P1 | 消费方确认 |
| Feature flag 默认开启影响全量用户 | P2 | Release Gate 灰度策略 |

## 输出格式（暂停时）

```text
[risk] 等级：P0|P1|P2
现象 / 拟议动作：
影响范围：
回退方式：
需您确认：同意 / 修改 / 取消
```

## 与 COMMON_AGENT_RULES 对齐

Git / 工作区还原规则以 `AGENTS.md` / `COMMON_AGENT_RULES.md` 为准；本矩阵补充研发治理类风险。
