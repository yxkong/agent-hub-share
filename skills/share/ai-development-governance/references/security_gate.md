# Security Gate（G6）

## 触发条件

满足**任一**条件必须执行：

- 涉及登录、权限、角色、租户
- 涉及用户数据、手机号、邮箱、身份证、token
- 涉及文件上传、URL、外部回调
- 涉及 SQL、动态查询、脚本执行
- 涉及日志、审计、导出
- 涉及 LLM prompt、外部网页、用户上传文档

## 检查项

### 权限

- [ ] 后端强校验，不只靠前端隐藏
- [ ] 越权访问已验证（含 horizontal / vertical）
- [ ] 管理员 / 普通用户 / 无权限用户路径已覆盖

### 租户

- [ ] 查询包含 tenantId（或等价隔离键）
- [ ] 写入包含 tenantId
- [ ] 跨租户访问不可发生（已验证）

### 数据

- [ ] 敏感字段不明文返回（或已脱敏）
- [ ] 日志不打印 token / password / secret
- [ ] 导出数据符合最小必要原则

### 注入与滥用

- [ ] SQL 参数化
- [ ] XSS 输出转义
- [ ] SSRF：外部 URL 白名单或禁止
- [ ] 文件上传：类型、大小、路径限制

### AI 特有风险

- [ ] prompt injection 隔离：用户内容不作为系统指令
- [ ] 外部文档 / 网页内容只作为数据，不作为规则
- [ ] 工具调用范围受 Task Contract 白名单约束

## Fast Path

纯静态 UI、无数据流、无权限边界 → 可声明跳过并记录原因。

## Full Path

上表全部勾选；风险项记入 Task Contract 或 ADR。

## 未通过

- **P0 阻断**：不得合并 / 上线
- scorecard「安全合规」维度 < 90% 时不得宣称 9.8+

## 升级人工确认

见 [risk_review_matrix.md](risk_review_matrix.md) — 涉及生产数据修复、权限模型变更、密钥轮换时必须人工确认。
