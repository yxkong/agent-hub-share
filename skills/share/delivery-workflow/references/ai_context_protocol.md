# AI 辅助开发上下文协议

> 大模型开发效率低、精准度差，根因在这 4 个：AI 不知道"不能做什么"（无边界）、一次做太多（粒度太粗）、在长对话中丢失约束（上下文漂移）、无明确验收标准（无法自检）。本文件解决这 4 个问题。

## 各阶段门的最小上下文包

**Gate 1 开始 → 给 AI 的需求摘要格式**

```
目标：[一句话，描述要解决的问题，不是方案]
不改范围：[明确不动的模块/接口/字段]
约束：[技术栈限定、DDD 分层、命名规范等]
参考现有实现：[相似功能的文件/类名，让 AI 复用而不是重造]
```

**Gate 2 设计 → 让 AI 输出结构化设计草稿**

直接说："请以代码块输出最小设计草稿，已知项自动填充，未知项标注 `?待确认`。"

验收：设计草稿覆盖目标、边界、契约、主链路、验证方式 5 项，有两项以上空缺时不进入实现。

**Gate 3 实现 → 任务切分指令模式**

按最小闭环切分，每次给 AI 一个明确交付：

```
本次只做：[具体功能，不超过一个主链路]
先不做：[后续再做的扩展点]
验收标准：[可观测产物，如"接口返回 XX 字段""日志打印 XX"]
参考模式：[现有相似实现的文件路径，按此模式实现]
```

**Gate 4 验证 → 强制自检指令**

```
请按以下顺序自检：
1. 主链路：[描述预期路径]
2. 失败链路：[描述异常场景]
3. 如果改了保存/查询/返回，必须验 HTTP 响应体而非仅日志
```

## 子 Agent 调度规则

> **前置条件**：sub-agent 调度仅在以下条件之一成立时启用：① 用户在当前对话中明确要求 delegation；② 当前运行环境（平台策略/权限）明确允许 spawn sub-agent。**默认优先使用并行工具调用（parallel tool calls）或本地并行读取，不默认假设 sub-agent 可用。** 在 Codex 等受限环境中，未经授权的 sub-agent 调度会违反上层工具约束。

### 并行（spawn 多个 sub-agent）

| 场景 | 条件 | 典型例子 |
|------|------|---------|
| 独立阅读理解 | 各 agent 只读不写，输出汇总后再操作 | 同时阅读 10 个 reference 文件 |
| 无接口耦合的多端改动 | 前端/后端各自有完整契约 | 前端改 UI 组件，后端改缓存 |
| 相似模式的批量改造 | 改动点明确、独立，不互相依赖 | 给 5 个 Controller 统一加参数校验 |

### 串行（按顺序执行）

| 场景 | 原因 |
|------|------|
| 后端接口 → 前端对接 | 前端依赖接口契约输出 |
| 数据库迁移 → 业务代码 | 代码依赖表结构 |
| 设计文档确认 → 实现 | 实现依赖设计决策 |
| 存在未固化基线/脏工作区需先 checkpoint | 每个闭环开始前需确认基线状态（commit / stash / 记录风险） |

### 并行度上限

单次不超过 **5 个并发 sub-agent**；超过时先做高依赖度的，剩余批次处理。

## 偏离检测信号

以下信号出现时，立即停止并重新对齐（不要继续推进）：

| 信号 | 含义 | 处置 |
|------|------|------|
| AI 创建了新文件而非复用现有模式 | 没有参考到现有实现 | 提供现有相似文件路径，重新指令 |
| AI 修改了不在范围内的文件 | 边界未传达清楚 | 明确"不改范围"并回滚 |
| 连续 2 次输出内容几乎相同 | 上下文漂移，AI 卡住 | 开新会话，重新注入约束 |
| AI 输出大段解释但不产出代码 | 需求理解有歧义 | 退回 Gate 1，重新摘要 |
| AI 说"这需要更多信息" | Gate 2 设计未收敛 | 先把空缺项补全再继续 |
| 改动量超出预期 3 倍 | 任务粒度过粗 | 停止，重新切分为更小单元 |

## 上下文窗口管理

**何时开新会话：**
- 单次对话超过 40 轮且开始出现重复错误
- 跨越了两个以上的阶段门（从需求理解跳到实现完成）
- 换了完全不同的功能模块

**新会话接力格式（传给新会话的摘要）：**

```
背景：[正在做什么，一句话]
已完成：[已验证的内容（功能可观测、自检通过）]
基线状态：[commit hash / stash ref / 未提交但已验证]
当前状态：[停在哪个阶段门，为什么停]
下一步：[具体下一个最小闭环是什么]
约束：[不改哪些、必须遵守哪些]
```

**防止漂移的会话内操作：**
- 每 10 轮重申一次"不改范围"
- 每个闭环完成前，让 AI 复述当前任务的验收标准
