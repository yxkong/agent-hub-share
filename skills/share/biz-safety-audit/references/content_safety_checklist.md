# 内容安全审计 Checklist

## 适用场景

用户可提交文本、富文本、评论、图片、文件、链接等任意内容（UGC）的功能。

---

## 1. 输入限制

### 1.1 长度与格式

- [ ] 文本字段设置合理的**最大长度**（后端校验，不只前端）
- [ ] 富文本限制允许的 HTML 标签白名单（禁止 `<script>`、`<iframe>`、`<object>` 等）
- [ ] 文件上传限制：类型白名单、大小上限、文件名长度
- [ ] 图片上传：尺寸/分辨率上限、格式白名单（jpg/png/webp）
- [ ] 多行文本限制最大行数，防止超长内容撑爆页面

### 1.2 编码与转义

- [ ] 用户输入在**存储前**做必要的清洗（strip tags / sanitize）
- [ ] 用户输入在**展示时**做输出转义（防 XSS）
- [ ] URL 类字段验证协议白名单（`http/https`），禁止 `javascript:` 等
- [ ] 文件名不允许路径穿越字符（`../`、`\`）

## 2. 敏感词与内容审核

### 2.1 敏感词过滤

- [ ] 建立敏感词库（分级：违法 / 政治 / 色情 / 广告 / 自定义业务词）
- [ ] 支持**多种匹配**：精确匹配、模糊匹配、变体检测（谐音/拆字/繁简/emoji 替代）
- [ ] 命中敏感词后的处理策略明确：拦截 / 替换为 `***` / 进入人工审核
- [ ] 敏感词库可动态更新（不需要重启服务）
- [ ] 日志记录命中的敏感词和原始内容（脱敏后留痕）

### 2.2 内容审核流程

- [ ] 高风险内容（首次发布 / 高频发布用户）进入**先审后发**
- [ ] 低风险内容可**先发后审**，但必须有异步审核机制
- [ ] 审核结果可追溯：审核人、审核时间、处置决定
- [ ] 审核不通过的内容有**用户通知**机制（告知原因或申诉入口）
- [ ] 批量内容操作（导入、群发）必须走审核流程

### 2.3 AI / 第三方审核集成

- [ ] 图片 / 视频内容审核接入第三方服务或 AI 模型（鉴黄/鉴暴/OCR 敏感字）
- [ ] 第三方审核服务不可用时有**降级策略**（排队人工 / 限制发布）
- [ ] 审核结果缓存策略合理（相同内容不重复调用）

## 3. 反垃圾 / 反灌水

- [ ] 同一用户发布内容有**频率限制**（如每分钟 N 条）
- [ ] 重复内容检测（连续发布相同或高度相似内容拦截）
- [ ] 新注册用户有发布冷却期或额度限制
- [ ] 批量注册小号灌水的检测与处置
- [ ] 含多个外链的内容标记为疑似广告

## 4. 用户举报与处置

- [ ] 提供用户举报入口（内容 / 评论 / 私信）
- [ ] 举报有分类（广告 / 色情 / 骚扰 / 侵权 / 其他）
- [ ] 被举报内容达阈值自动下架或进入人工审核
- [ ] 举报处理结果反馈给举报人
- [ ] 恶意举报检测（高频举报同一用户 / 互相举报）

## 5. 内容生命周期

- [ ] 删除的内容做**软删除**（保留审计记录）
- [ ] 编辑历史可追溯（至少保留最近 N 个版本）
- [ ] 内容发布后的修改仍需过审核（防止先发正常内容再改为违规）
- [ ] 过期/下架内容的清理策略明确

## 审计结论分级

| 级别 | 定义 | 示例 |
|------|------|------|
| **P0 阻断** | 缺失将直接导致安全事故 | 无 XSS 防护、无敏感词过滤、文件上传无类型限制 |
| **P1 建议** | 缺失显著增加风险 | 无内容审核流程、无频率限制、无举报机制 |
| **P2 可选** | 提升安全成熟度 | AI 审核集成、编辑历史追溯、恶意举报检测 |
